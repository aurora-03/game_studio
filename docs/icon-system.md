# 界面图标

工作台图标参考 LibTV 实际画布的细线轮廓、几何类别符号、32px 工具按钮和中性灰状态。图形由项目自行绘制，不依赖远端资源。游戏作品、模板封面与界面图标分别处理。

- `src/components/StudioIcons.ts` 统一节点、工作流、素材库、整理、历史与导演图标。类别图标同时用于节点、添加菜单和 `@` 候选。
- 使用 24px 坐标系、1.5px 线宽；主要工具显示 20px，普通操作显示 18px，节点与引用显示 13–16px。
- 灰色为默认，白底深色表示主要添加操作；青色仅用于连接、选择和引用等功能状态。
- 不使用闪光星、魔法棒、发光球和渐变图标底座。未生成的游戏显示空预览框，已有游戏保留实际预览。
- 所有仅图标按钮保留名称、提示、禁用状态与键盘焦点。图标更新不改变工作流、模型、素材或项目数据。
