# GameStudio 验收标准

目标：在 `/Users/amiao/Project/gamestudio` 实现一个参考 LibTV 创作网站与工作台设计的 AI 游戏生成网站。真实生成通过本机 Codex CLI 调用 `gpt-6.1-sol`；用户能够从想法进入项目、建立工作流、生成可玩的游戏、修改并导出。

参考资料：本次已登录实查的 LibTV 调研报告和 13 张截图，保存于 `/Users/amiao/Documents/Codex/2026-10-02/ni-q/outputs/libtv-research/`。仿照的是视觉语言、信息架构与连续创作流程；视频专用操作应转为游戏创作中的对应能力。

## 交付与运行

- [x] 代码及运行文档位于指定目录；安装、开发和正式运行命令可执行。
- [x] 健康检查能显示 CLI 是否可用、登录状态以及固定模型 `gpt-6.1-sol`。
- [x] 页面显示真实后端状态，CLI 不可用、未登录、生成失败时提供真实错误和下一步操作。
- [x] 不需要 API Key；不把 Codex 登录凭据写入项目或前端。

## 网站与视觉

- [x] 首页有深色导航、创作入口、项目续作入口、模板/示例与可用功能入口。
- [x] 工作台使用深色点阵画布、可操作节点、连线、顶部项目栏和底部工具条。
- [x] 样式采用 LibTV 相近的黑灰背景、细边框、卡片、圆角和亮色强调；实际渲染截图验证，而非仅检查 CSS。
- [x] 所有展示为可点击的主要入口都有功能或明确的空状态；无伪造成功、无占位按钮。
- [x] 桌面与窄屏布局能操作，模态框、滚动区域、长文本与按钮不会被裁切。

## 项目与素材

- [x] 新建、重命名、描述编辑、搜索、复制、归档、回收站恢复与永久删除按 UI 约定工作。
- [x] 项目、布局、设置、对话、素材、版本与激活版本重启后保留。
- [x] 项目复制生成独立 ID；复制后的编辑不会更改原项目。
- [x] 本地素材上传、显示、删除能完成；生成输入可以引用项目素材。
- [x] 模板能建立有意义的游戏需求与工作流，而非只改变标题。

## 工作台与工作流

- [x] 添加、选择、编辑、移动、删除节点；连接和删除依赖关系。
- [x] 缩放、拖动画布、适合屏幕与布局整理可用；视图在重新进入项目后恢复。
- [x] 工作流和素材/版本看板使用同一项目数据。
- [x] 生成参数能影响任务；界面明确固定使用本地 `gpt-6.1-sol`。
- [x] AI 助手接收创作要求和项目上下文；任务产物进入项目节点与版本历史。
- [x] 不同项目与节点的结果不会串写；正在编辑的数据不会被进度事件覆盖。

## 真实生成与返工

- [x] 用真实 `codex exec` 提交一次初始生成，记录任务 ID、模型、结果和可玩的预览。
- [x] 任务经历排队/运行/成功或失败状态，日志与 SSE 事件能反映进展。
- [x] 对已有版本提交一次真实修改；修改结果保存成新版本，原版本保留。
- [x] 参数、素材和已有源代码进入生成上下文；任务不依赖固定演示 HTML。
- [x] 取消排队或运行任务会进入取消状态，进程退出，且不会写入成功版本。
- [x] 错误 CLI、非零退出、缺失产物与重启时未完成任务有明确终态，不永远停在运行中。
- [x] 活跃任务期间禁止不兼容的项目永久删除，或取消并收尾后再删除。

## 游戏、版本与交付

- [x] 预览沙箱能玩真实生成的游戏，键鼠/触摸操作与得分/输赢机制正常。
- [x] 浏览器可切换预览与源码，编辑源码保存新版本，并恢复任意历史版本。
- [x] 游戏预览无法直接读取工作台 DOM、登录凭据或敏感本地文件。
- [x] HTML 导出能独立在浏览器运行；ZIP 内含可打开的入口文件及必要资源。
- [x] 空项目没有伪造预览；没有版本时导出返回明确错误。
- [x] 导出、删除、上传和文件服务路径均约束在对应项目目录。

## 验证记录

最终 `npm test` 通过 32 项测试，其中 HTTP 集成测试 15 项。该套测试使用受控 CLI 夹具覆盖任务队列、故障与持久化；真实模型生成、浏览器玩法与视觉另有实测证据，记录在 `docs/verification.md`。

只有每项都有当前文件、测试输出、运行结果或浏览器截图证据时才完成验收；没有失败证据不等于已经证明成功。
